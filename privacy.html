1. Introduction & Commitment

Tempo (“we,” “our,” or “the Application”) is an engineering-driven productivity workspace committed to radical transparency and data minimization. This Privacy Policy details how we handle user data across our web application (https://tempo-ofxg.onrender.com) and APIs.

We do not sell, rent, monetize, or broker personal information. Our business model is focused strictly on delivering focused, high-performance task management tools.

2. Information We Collect

We collect only the minimum data required to provide task organization services:

  • Account Credentials: When creating a registered account, we collect your full name, username, email address, and a cryptographically salted password (hashed using bcrypt with 10 salt rounds). Plaintext passwords are never stored or logged.
  • Task & Project Data: Content created within the workspace, including task titles, priority levels (low, medium, high), due dates, completion statuses, and project categorizations.
  • Technical Metadata: Standard HTTP request logs (IP address, user agent, response times) strictly utilized for DDoS mitigation, rate limiting, and server diagnostic logs.

3. Ephemeral Guest Mode (Unauthenticated)

Tempo offers an unauthenticated Guest Mode allowing immediate task management without creating an account:

  • Guest operations exist strictly in client-side volatile browser memory.
  • Guest tasks and custom projects are never written to our Neon PostgreSQL database or permanent server storage.
  • Refreshing the browser or clearing the tab automatically resets guest data, ensuring complete zero-residue privacy.

4. Multi-Tenant Data Isolation

For registered accounts, Tempo enforces strict row-level multi-tenant database isolation. Every database query, API transaction, and cache operation is scoped exclusively to the authenticated user ID extracted from a validated JSON Web Token (JWT).

Cross-account data leakage, foreign resource enumeration, and unauthorized cross-tenant modifications are actively tested and blocked by automated regression test suites.

5. Data Storage & Infrastructure

Our application infrastructure is hosted with trusted cloud partners maintaining high compliance standards:

  • Database: Serverless PostgreSQL hosted with Neon, featuring encryption at rest and encrypted TLS 1.3 connections in transit.
  • Application Hosting: Express.js container hosted on Render with reverse-proxy TLS termination and automated DDoS filtering.

6. Cookies & Local Storage

Tempo does not use third-party analytics, behavioral tracking, cross-site trackers, or advertising cookies:

  • tempo_auth_token: Scoped JWT token enabling authenticated API interactions.
  • tempo_theme: Stores your chosen color palette (e.g., Carbon & Sage Teal, Neo-Brutalist Light, Dark).
  • tempo_sidebar_collapsed: Preserves your layout preference for sidebar width.

7. Data Retention & User Rights

You maintain full ownership of your productivity content:

  • Right to Deletion: You may delete individual tasks, projects, or discard unsaved changes at any time.
  • Right to Correction: Profile details can be updated directly from the Settings & Preferences screen.
  • Account Purge: Requests to permanently expunge account records may be submitted to our privacy contact.

8. Vulnerability Reporting

Security researchers and users may review our coordinated vulnerability disclosure policy at /.well-known/security.txt.
